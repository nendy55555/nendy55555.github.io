Tech Jargon · Project № 08

Coupon Tracker

A junk-drawer of promo codes that finally files itself, flags the ones about to expire, and surfaces the right one the moment you open checkout.

The Analogy

The wallet that remembers for you.

You hoard codes like gum wrappers. Newsletters, cashback sites, that one Reddit thread — each promises 15% off something you'll buy eventually. Then checkout arrives and you can't find a single one. The savings die in a screenshot folder you never open.

This tool turns that mess into a working wallet. It reads every promo you've been sent, tags what it's good for, watches the clock on expirations, and hands over the best available code the instant you're about to pay.

A coupon you can't find at checkout is worth zero. The fix is recall, not collection.
How It Works

Catch. Organize. Deploy.

Input
It catches every code.
Parses promo emails, scans cashback feeds, and pulls store-specific codes into one store-tagged ledger — no manual filing.
→
Transform
It sorts and scores.
Tags each code by merchant, category, minimum cart, and expiration. Flags stacking rules. Kills duplicates. Ranks by actual dollar impact.
→
Output
You get the winner at checkout.
The right code, surfaced on the right site, before you click pay. No tab-hopping, no expired-code rage.
Under the Hood

What's actually running.

Collector Inbox & Feed Parser Reads promo emails and scans cashback sources. Extracts the code, the merchant, and the fine print.
Librarian Tagging Engine Categorizes each code by store, product type, and stacking rules so the right one surfaces in context.
Clock Expiration Watcher Tracks expiry dates and pings you when a high-value code is about to go stale on a store you actually use.
Courier Checkout Surface A browser companion that matches the page you're on to the best available code — one click to apply.
Why it's built this way

The hard part isn't finding codes — inboxes overflow with them. The hard part is recall at the exact moment of purchase. Splitting the system into collect, tag, watch, and deliver means each part can get smarter on its own, and the whole stack gets more useful every time a new merchant or source is added.

Why It Matters

Small savings compound quietly.

A 15% code on every order you were going to place anyway stacks up to a meaningful dent over a year. The barrier isn't greed — it's the friction of remembering. Remove that friction and the savings arrive on autopilot.

This one isn't about becoming an extreme couponer. It's about not leaving free money on the table because you forgot where you put it.
